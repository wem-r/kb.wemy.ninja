Windows shortcuts

| Shortcut | Action |
|---|---|
| `Win` | Toggle Start menu |
| `Win` + `A` | Toggle Action Center / notification screen |
| `Win` + `B` | Set focus to system tray icon |
| `Win` + `C` | Open Cortana in listening mode |
| `Win` + `Shift` + `C` | [Win 8] Open the charms menu / [PowerToys] Open color picker |
| `Win` + `D` | Toggle desktop |
| `Win` + `Alt` + `D` | Toggle date and time taskbar menu |
| `Win` + `E` | Open File Explorer |
| `Win` + `F` | Open Feedback Hub and take a screenshot |
| `Win` + `G` | Toggle Game Bar |
| `Win` + `H` | Toggle dictation |
| `Win` + `I` | Open/focus Settings |
| `Win` + `J` | Set focus to a Windows tip, if available |
| `Win` + `K` | Toggle Connect menu |
| `Win` + `L` | Lock PC |
| `Win` + `M` | Minimize all windows |
| `Win` + `O` | Toggle device orientation lock |
| `Win` + `P` | Toggle multi-display mode menu |
| `Win` + `Ctrl` + `Q` | Open Quick Assist |
| `Win` + `R` | Open/focus Run dialog box |
| `Win` + `S` | Open search (or just press `Win` and start typing) |
| `Win` + `Shift` + `S` | Toggle Snip & Sketch |
| `Win` + `T` | Cycle through apps on the taskbar |
| `Win` + `U` | Open/focus Ease of Access Center |
| `Win` + `V` | Open clipboard history (must be enabled first) |
| `Win` + `Shift` + `V` | Cycle through notifications |
| `Win` + `X` | Open Quick Link menu (press the underlined letter to continue) |
| `Win` + `Y` | Toggle Windows Mixed Reality and desktop, if available |
| `Win` + `Z` | [Win 8?] Show commands available in a full-screen app |
| `Win` + `.` (or `Win` + `;`) | Emoji picker (can switch to symbols and ASCII emoticons) |
| `Win` + `,` | Peek at desktop |
| `Win` + `Pause` | Open/focus System Properties |
| `Win` + `Ctrl` + `F` | Search for PCs (on a network) |
| `Win` + `Shift` + `M` | Restore minimized windows on the desktop |
| `Win` + `0-9` | Open/focus/minimize the app pinned at that taskbar position |
| `Win` + `Shift` + `0-9` | Open a new instance of that pinned app |
| `Win` + `Ctrl` + `0-9` | Open that app / focus its last active window |
| `Win` + `Alt` + `0-9` | Open the jump list of that pinned app |
| `Win` + `Ctrl` + `Shift` + `0-9` | Open a new instance of that pinned app as admin |
| `Win` + `Tab` | Toggle Task View |
| `Win` + `↑` | Maximize the active window |
| `Win` + `↓` | Unmaximize/minimize the active window |
| `Win` + `←` or `→` | Snap active window left/right (moves it across monitors) |
| `Win` + `Home` | Toggle minimizing all windows except the active one |
| `Win` + `Shift` + `↑` | Stretch the window to the top and bottom of the screen |
| `Win` + `Shift` + `↓` | Restore/minimize the window vertically, keeping its width |
| `Win` + `Shift` + `←` or `→` | Move the active window to another monitor |
| `Win` + `Space` | Switch input language and keyboard layout |
| `Win` + `Ctrl` + `Space` | Change to the previously selected input |
| `Win` + `Ctrl` + `Enter` | Toggle Narrator |
| `Win` + `+` | Open Magnifier / zoom in |
| `Win` + `/` | Begin IME reconversion (foreign alphabets) |
| `Win` + `Ctrl` + `V` | Open shoulder taps |
| `Win` + `Ctrl` + `Shift` + `B` | Wake PC from a blank or black screen |
| `Ctrl` + `Shift` + click (or `Enter`) | Run a program as admin |

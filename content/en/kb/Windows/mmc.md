# Microsoft Management Console (MMC)

> Tip: run `dir C:\Windows\System32\*.msc` to list every console installed on a given machine

| Command               | Console                                                                |
|-----------------------|------------------------------------------------------------------------|
| `mmc.exe`             | _Empty MMC console_ (add your own snap-ins)                            |
| `adsiedit.msc`        | _ADSI Edit_ (Server / RSAT)                                            |
| `azman.msc`           | _Authorization Manager_                                                |
| `certlm.msc`          | _Certificates Manager (local machine)_                                 |
| `certmgr.msc`         | _Certificates Manager (current user)_                                  |
| `certsrv.msc`         | _Certification Authority_ (AD CS role)                                 |
| `certtmpl.msc`        | _Certificate Templates_                                                |
| `cluadmin.msc`        | _Failover Cluster Manager_ (Failover Clustering)                       |
| `comexp.msc`          | _Component Services_ (same as `dcomcnfg`)                              |
| `compmgmt.msc`        | _Computer Management_                                                  |
| `devmgmt.msc`         | _Device Manager_                                                       |
| `dfsgui.msc`          | _Distributed File System GUI (legacy)_                                 |
| `dfsmgmt.msc`         | _Distributed File System Management_                                   |
| `dhcpmgmt.msc`        | _Dynamic Host Configuration Protocol (DHCP) Management_                |
| `diskmgmt.msc`        | _Disk Management_                                                      |
| `dnsmgmt.msc`         | _Domain Name System (DNS) Management_                                  |
| `domain.msc`          | _Active Directory Domains and Trusts_ (Windows Server only)            |
| `dsa.msc`             | _Active Directory Users and Computers_ (Windows Server only)           |
| `dssite.msc`          | _Active Directory Sites and Services_ (Windows Server only)            |
| `eventvwr.msc`        | _Event Viewer_                                                         |
| `fsmgmt.msc`          | _Shared Folders Management_                                            |
| `fsrm.msc`            | _File Server Resource Manager_ (FSRM role)                             |
| `gpedit.msc`          | _Local Group Policy Editor_ (not on Home)                              |
| `gpmc.msc`            | _Group Policy Management_ (Server / RSAT)                              |
| `gpme.msc`            | _Group Policy Management Editor_ (Server / RSAT)                       |
| `gptedit.msc`         | _Starter GPO Editor_ (Server / RSAT)                                   |
| `lusrmgr.msc`         | _Local Users and Groups Manager_ (not on Home)                         |
| `napclcfg.msc`        | _Network Access Protection (NAP) Client Configuration_                 |
| `nfsmgmt.msc`         | _Services for Network File System (NFS)_                               |
| `nps.msc`             | _Network Policy Server_ (NPS role)                                     |
| `ocsp.msc`            | _Online Responder Management_ (AD CS role)                             |
| `perfmon.msc`         | _Performance Monitor_                                                  |
| `pkiview.msc`         | _Enterprise PKI_ (AD CS role)                                          |
| `printmanagement.msc` | _Print Management_                                                     |
| `rrasmgmt.msc`        | _Routing and Remote Access_ (RRAS role)                                |
| `rsop.msc`            | _Resultant Set of Policy_                                              |
| `schmmgmt.msc`        | _Active Directory Schema_ (run `regsvr32 schmmgmt.dll` first)          |
| `secpol.msc`          | _Local Security Policy_ (not on Home)                                  |
| `services.msc`        | _Services_                                                             |
| `tapimgmt.msc`        | _Telephony_                                                            |
| `taskschd.msc`        | _Task Scheduler_                                                       |
| `tpm.msc`             | _Trusted Platform Module (TPM) Management_                             |
| `tscc.msc`            | _Terminal Services Configuration Console_                              |
| `tsgateway.msc`       | _Remote Desktop Gateway Manager_ (RD Gateway role)                     |
| `virtmgmt.msc`        | _Hyper-V Manager_ (Hyper-V)                                            |
| `wbadmin.msc`         | _Windows Server Backup_ (Server)                                       |
| `wdsmgmt.msc`         | _Windows Deployment Services_ (WDS role)                               |
| `wf.msc`              | _Windows Defender Firewall with Advanced Security_                     |
| `winsmgmt.msc`        | _WINS Management_ (WINS feature)                                       |
| `wmimgmt.msc`         | _Windows Management Instrumentation (WMI) Management_                  |

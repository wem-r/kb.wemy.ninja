This site is built with [Hugo](https://gohugo.io/) and the
[Docsy](https://www.docsy.dev/) theme, and deployed to GitHub Pages by
GitHub Actions on every push to `main`.

> This is a Markdown alert. Obsidian callouts use the same `> [!type]` syntax.

> [!WARNING] Custom title
> Alerts can have a title too.

```bash
npm ci && npm run serve
```

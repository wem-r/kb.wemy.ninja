>Exemple de missions TSSR :  
>• Configurer les éléments actifs d’un réseau local d’entreprise  
>• Assurer la gestion du parc WIFI d’un ESN  
>• Monter une machine virtuelle  
>• Gérer les serveurs windows dans un LAN  
>• Gérer une architecture AD répliquée  
>• Installer et configurer une solution de support/inventaire type GLPI  
>• Assurer le support/helpdesk niveau ½ d’une ESN  
>• Gérer le parc Téléphonique d’une société  
>• Configurer un serveur VoIP  
>• Manipuler un Cluster D’ESX  
>• Créer des Machines Virtuelles dans le cloud  
>• Former les utilisateurs sur les outils bureautique  
>• Gérer les comptes Microsoft365  
>• Monter un service de partage de fichier  
>• Utiliser un outil de supervision type Zabbix  
>• Gérer le firewall d’une entreprise  
>• Créer des VPN user-to-site
